The Scrapely API client for Python is the official library to access the [Scrapely REST API](https://scrape.ly/docs/api) from your Python applications. It provides useful features like automatic retries and convenience functions that improve the experience of using the Scrapely API.

The client simplifies interaction with the Scrapely platform by providing:

- Intuitive methods for working with [Actors](https://scrape.ly/docs/actors), [Datasets](https://scrape.ly/docs/storage#datasets), [Key-value stores](https://scrape.ly/docs/storage#key-value-stores), and other Scrapely resources
- Both synchronous and asynchronous interfaces for flexible integration
- Built-in [retries with exponential backoff](../02_concepts/05_retries.mdx) for failed requests
- Comprehensive API coverage with JSON encoding (UTF-8) for all requests and responses

## Prerequisites

`scrapely-client-python` requires Python 3.11 or higher. Python is available for download on the [official website](https://www.python.org/downloads/). Check your current Python version by running:

```bash
python --version
```

## Installation

The Scrapely client is available as the `scrapely-client-python` package [on PyPI](https://pypi.org/project/scrapely-client-python/). The import name is `scrapely_client`.

```bash
pip install scrapely-client-python
```

For better request-body compression, opt in to `brotli`, which compresses better than `gzip`, especially for large payloads. Install the optional extra:

```bash
pip install "scrapely-client-python[brotli]"
```

For details, see [HTTP compression](../02_concepts/13_http_compression.mdx).
